Kit setup for freelancers: a simple first-week checklist

Start with one clear signup path and one useful email. Add automation only after the basic flow works.

Fact-checked September 5, 2026

Editorial note: Navigation and feature details are based on Kit’s official documentation. This guide does not claim hands-on testing. No affiliate links are included.

What to set up first

  1. Define what subscribers will receive.
  2. Create one tag for the signup source.
  3. Build one form or landing page.
  4. Review the confirmation email.
  5. Test the signup yourself.
  6. Send one broadcast.

1. Write a one-sentence audience promise

Before opening the builder, finish this sentence: “Subscribe to receive ___ for ___.” Keep the promise narrow enough that a new subscriber understands the topic and expected value.

2. Create a source tag

Use a tag such as Source — Website — CRM guide. Tags help record where a subscriber entered or what they expressed interest in. Avoid creating many tags before you have a real use for them.

3. Choose a form or landing page

Kit directs users to Audience growth → Landing Pages & Forms → + New. Choose a form when you can embed it on an existing site. Choose a landing page when you need a standalone signup URL.

4. Review consent and confirmation

Make the button and surrounding copy describe what the person is requesting. Review the confirmation email and incentive delivery before publishing. Do not add people who have not consented to receive marketing email.

5. Test the full path

  1. Subscribe with an address you control.
  2. Confirm that the success message or thank-you page appears.
  3. Check that the confirmation or incentive email arrives.
  4. Confirm the subscriber appears with the intended tag.
  5. Test the unsubscribe link in a separate test if appropriate.

6. Send the first broadcast

Broadcasts are one-time emails. Kit’s current navigation uses Broadcasts → + New Broadcast. For the first send, choose a clear subject, explain why the reader is receiving it, deliver the promised value, and send a test before publishing.

7. Decide whether automation is justified

Kit’s Free plan supports forms and unlimited broadcasts, while email sequences and full visual automations are paid features. Do not upgrade merely to copy a complicated template. Upgrade when a repeatable welcome or nurture process is already defined.

Week 1

One promise, one form, one tag, one test subscriber.

Week 2

Send a useful broadcast and review replies or clicks.

Later

Add segments, sequences, or integrations only when volume requires them.

Connect Kit to your sales process

Kit manages subscribers and audience communication. A CRM tracks individual opportunities and next actions. Define when an engaged subscriber becomes a lead using the framework in Kit vs. a CRM.
